# v9 수정 내역

- 15장을 전체 검토해 이론·사례·비교·진단의 읽기 경로를 왼쪽 세로 탭으로 표시했다.
- 3장에는 외부·내부 변수에서 옹호–수용 연속선으로 내려가는 화살표를, 6·8장에는 사실에서 이론적 해석으로 넘어가는 별도 색상 박스와 화살표를 넣었다.
- 11장에 Cameron의 조건 분석 → Benoit의 메시지 판독 → 공식 원문으로 확인한 행동·결과의 흐름을 추가했다.
- 12장 비교 행의 크기를 키웠고, 13장에는 이론의 질문 → 사례 평가 기준을 연결하는 가로 레일을 만들었다.
- 15장의 이론 문헌 두 구역을 하나로 합치고, 모든 이론·사례 문헌을 화면 너비 전체에 가로 목록으로 배치했다.

## v8에서 이어진 내용 검증

- Cameron 정황적 수용 이론을 주 분석 틀로 유지하고, Benoit(1997)의 이미지 회복 전략을 공식 발화 분석에 한정해 추가했다.
- 강원대 제46·47·48차 평의원회 회의록을 대조해 자료 지연에 대한 사과, 협상 보안·기한 해명, 인력 구성안 수정 설명을 슬라이드 6·7·11에 반영했다.
- 동덕여대 대학본부의 2024.11.18 소통 일지와 2025.12.03 총장 입장문을 공론화 자료 및 학칙 개정 공고와 대조해 슬라이드 8–11에 반영했다.
- 근거가 불충분한 책임회피·공격자 비난 분류를 사용하지 않았고, 전략의 발화와 후속 행동을 구분했다.
- 제46차 회의록에 맞춰 257쪽 자료 제공 시점을 ‘당일 배부’에서 ‘이틀 전 송부’로 수정했다.
- 동덕여대 2024.11.21 합의는 양측 서명 원본 미확보 상태에 맞춰 ‘합의 보도’로 표기했다.
- 기존 15장 구성, 이미지, 서체, 색상, 상호작용을 유지했다.
