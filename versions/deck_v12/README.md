# 발표덱 v12

강원대 통합과 동덕여대 남녀공학 전환을 **카메룬의 정황적 수용 이론**으로 분석한 15장 HTML 덱이다. 81개 상황변수를 전수 평가한 보고서를 연결했고, 베노이트의 이미지 회복 전략은 14장 한 장에서만 설명한다. v11 이전 판은 보존했다.

- [발표 열기](index.html) · [인쇄용 PDF](deck_v12.pdf)
- [81개 변수 전수분석](카메룬_81개_변수_전수분석.md) · [원본 변수 목록](카메룬%20위기%20상황변수%20목록.md)
- [공식 원문과 이론 출처](sources.html) · [참고문헌](deck_v12_참고문헌.md)

화살표 키로 슬라이드를 이동한다. `N`은 발표자 노트, `D`는 수치 검증, `M`은 목차, `P`는 인쇄 화면이다. 웹 덱과 PDF는 같은 HTML에서 만든다.

**근거 범위:** 강원대 인력 수정안은 공무원 35명 제안을 공무원 24명과 외부 전문가 11명으로 바꾸어 설명한 것이다. 총원 축소 또는 실제 인사 배치 완료로 해석하지 않는다. 동덕여대의 2029년 전환은 발표 전 설문에도 있었던 시점 조건을 포함한 계획이며, 학생의 여대 유지 요구 수용과 구별한다. 총투표 종료일은 자료마다 달라 12월 9일 결과 발표일로 표기했다.
