# 발표덱 v8

강원대–강릉원주대 통합과 동덕여대 남녀공학 전환 사례를 다룬 15장 HTML 발표자료다. v7의 구성과 디자인을 유지하고, Cameron의 정황적 수용 이론 아래 베노이트의 이미지 회복 전략 분석을 추가했다.

- [메시지와 후속 행동 대조표](베노이트_메시지_행동_대조.md)

화살표 키로 슬라이드를 이동한다. `N`은 발표자 노트, `D`는 자료 해설, `M`은 목차, `P`는 인쇄 화면이다.

전략 분류는 공식 입장문과 회의록에서 발화가 확인되는 경우에 한정했다. 2024년 동덕여대 잠정 중단은 합의 보도로 확인되며 양측 서명 원본은 확보되지 않았다. 강원대 인력 수정안의 실제 인사 배치와 동덕여대 반대 집단의 사후 수용은 확인되지 않았다.
