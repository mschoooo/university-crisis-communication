# deck_v4 · Editorial Archive

위기관리(029) 중간고사 대체 과제의 15장 편집 가능한 HTML 발표덱입니다. `index.html`을 브라우저에서 열면 됩니다. 인터넷 연결 없이 본문·수록 사진·글꼴이 표시됩니다. 표지의 동덕여대 현장 보도사진 링크를 열 때에는 인터넷 연결이 필요합니다.

## 제공 파일

- `index.html`, `style.css`, `slides.js`, `archive_details.js`, `assets/`: 편집 가능한 원본
- `deck_v4.pdf`: 16:9 발표·인쇄용 PDF
- `speaker_script.md`: 발표자 대본과 기존 v4의 상세 설명
- `asset_sources.md`: 슬라이드별 이미지·문서 출처, 촬영자, 날짜, 이용 조건
- `sources.html`: 원자료와 수업 문헌의 검증 인덱스

## 조작

오른쪽/왼쪽 방향키로 이동합니다. `N`은 발표자 노트, `M`은 목차, `D`는 핵심 수치 검증, `F`는 전체 화면을 엽니다. 발표자 노트에는 화면에서 줄인 기존 v4의 상세 본문도 들어 있습니다.

## 해석상 주의

- 동덕여대 2026학년도 지원자 감소율 32.9%는 외부 지원 동향의 참고 지표입니다. 원인은 확인되지 않았으며 2025년 12월 3일 발표가 앞선 9월 수시 접수 감소를 일으켰다고 볼 수 없습니다.
- 동덕여대 숙의기구 학생단은 구성원 12명으로 발표됐지만, 80%에서 50%로 제시된 비율의 회차별 유효 응답 모수와 동일 응답 여부는 확인되지 않았습니다.
- 강원대 조직안 조정과 4월 28일 가결은 모두 확인되지만, 조정이 가결을 일으켰다는 인과관계는 확인되지 않았습니다.

## 재현

프로젝트 폴더의 `scripts/render_editorial_deck.py`로 15장 스크린샷과 PDF를 재생성할 수 있습니다. `scripts/verify_editorial_pdf.py`는 PDF 페이지 수와 크기를 확인하고 각 페이지를 다시 렌더링합니다. 수치·표의 등장 효과는 브라우저 발표에서만 실행되며 PDF에는 최종 값이 고정됩니다. 모션 감소 설정을 켠 환경에서는 효과가 실행되지 않습니다.

현장 시위 보도사진은 재사용 조건을 확인하지 못해 파일에 복제하지 않았습니다. 표지에서 촬영자와 매체가 확인된 현장사진 원문으로 바로 이동할 수 있습니다. 덱에 수록한 사진은 실제 캠퍼스 기록사진이며, 사건 증거는 공개 공식 문서의 필요한 부분을 인용했습니다. 자세한 출처와 조건은 `asset_sources.md`에 적었습니다.
